AutoMaster AI 1.0 — первая версия без API-ключа

УСТАНОВКА НА IPHONE (бесплатный хостинг GitHub Pages)
1. Распакуйте ZIP. Откройте https://github.com/new и создайте публичный репозиторий automaster-ai (нужен аккаунт GitHub).
2. В репозитории выберите Add file → Upload files. Загрузите содержимое папки, а не саму папку или ZIP: index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png. README.txt можно тоже загрузить. Commit changes.
3. Settings → Pages → Build and deployment → Source: Deploy from a branch → main → / (root) → Save. После публикации GitHub покажет адрес сайта.
4. Откройте выданный HTTPS-адрес в Safari на iPhone. Поделиться → На экран «Домой» → Открывать как веб-приложение (если доступно) → Добавить.
5. Заполните карточку, подготовьте запрос, скопируйте, откройте ChatGPT, вставьте и отправьте. Фото прикладывайте там же. Текст ответа можно сохранить в истории приложения.

Приложение не является заводской ремонтной базой. В этой версии ответы и изображения получаются в ChatGPT, а не внутри AutoMaster. Интернет и доступ к ChatGPT обязательны для ответов ИИ. После первого открытия по HTTPS интерфейс может работать офлайн. История локальная; не публикуйте резервные копии и данные клиентов в GitHub. Отдельный API-ключ не нужен. Публичный репозиторий содержит только код приложения. Не размещайте туда личные данные.
